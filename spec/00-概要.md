# 概要

## 目的
本プロジェクトは、最終的に VS Code 拡張の WebView 上で動作する 2D CAD を実現することを目的とする。

初期段階では、同一の設計思想とアーキテクチャを維持した単体ブラウザアプリとして動作させ、設計検証、操作性確認、構成上の課題洗い出し、デバッグを行う。

## なぜ VS Code 拡張を最終目標とするのか
- 技術者の作業導線の中心にあるエディタ環境へ統合しやすい。
- プロジェクトファイルと近い位置で図面や設計情報を扱える。
- WebView により、モダンな UI と拡張機能連携を両立しやすい。

## なぜ初期は単体ブラウザアプリで進めるのか
- 拡張機能の梱包やホスト連携の複雑さを避け、操作性と構成の検証に集中できる。
- ブラウザ互換を前提とした設計を早期に固められる。
- WebView 移行時の差分を host adapter 層に閉じ込めやすい。

## プロダクトの現在位置
現時点では、汎用 2D CAD、回路図エディタ、EDA 補助ツールのいずれかに確定した状態ではない。
まずは、2D CAD の MVP を成立させるための共通基盤を設計対象とする。

## 現在フェーズ
- 使用検討および仕様策定フェーズ
- 実装は未着手
- 要件、アーキテクチャ、状態分離、ホスト連携方針の合意形成を優先する

## 初期前提
- UI フレームワーク候補は React
- 初期の実行環境は単体ブラウザアプリ
- 最終実行環境は VS Code 拡張の WebView
- 描画方式は Canvas 系を第一候補とするが、最終決定は保留
- 保存形式は内部・外部ともに JSON とする
