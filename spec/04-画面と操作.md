# 画面と操作

## 目的
本書は、MVP 検討段階における画面構成と操作モデルの叩き台を整理するための文書である。

## 画面設計の基本方針
- 初期段階では機能数よりも操作の明快さを優先する。
- 現在のツール、選択状態、スナップ状態が利用者に分かることを重視する。
- React は UI 構築を担当し、CAD の振る舞いはコア層に委譲する。

## 想定する画面構成
- 上部: ツールバー
- 左側: ツールパレット
- 中央: 作図キャンバス
- 右側: プロパティパネル
- 下部: ステータスバー

## 想定する主要ツール
- 選択
- パン
- 配線
- モジュール作成
- モジュール配置
- 選択アイテム削除
- テキスト

## 想定する基本操作
- Esc で現在の操作途中状態をキャンセルする。
- Undo/Redo は標準的なショートカットを前提に設計する。
- ズームはマウスホイールまたはトラックパッド操作に対応可能な構造にする。
- 単一選択と複数選択の両方を検討する。
- スナップの状態は視覚的に確認できることを目標とする。

## 選択中ハイライト
- モジュール: 矩形線を太くし、線色と塗りつぶし色を変更する。
- 配線: 同一信号名（ワイヤ名）を持つ配線をすべて太くし、線色を変更する。
- 端子: SVG アイコンを変更し、端子名テキストを Bold 表示にする。

## ステータス表示候補
- 現在ツール
- カーソル座標
- スナップ状態
- ズーム倍率

## 保留事項
- 操作感を CAD 寄りにするか、Figma 風にするか、EDA 風にするか。
- プロパティ編集を直接操作中心にするか、パネル中心にするか。
- 図形作成後に同じツールを維持するか、自動で選択ツールへ戻るか。
