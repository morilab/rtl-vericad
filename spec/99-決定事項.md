# 決定事項

## 目的
この文書は、合意済み事項、作業仮説、未決定事項を区別して記録するための文書である。
後から見返したときに「何が決まっていて、何がまだ保留か」がすぐ分かる状態を目指す。

## 合意済み事項

### D-001
決定:
- 最終目標は VS Code 拡張の WebView 上で動作する 2D CAD とする。

理由:
- 開発者向けワークフローとの統合価値が高いため。

状態:
- 合意済み

### D-002
決定:
- 初期フェーズでは、単体ブラウザアプリとして設計検証、操作性検証、デバッグを行う。

理由:
- 拡張機能パッケージ化の負担を避けつつ、CAD 特有の設計と操作性を早く検証できるため。

状態:
- 合意済み

### D-003
決定:
- 現在は使用検討・仕様策定フェーズとし、明示的な承認がない限り製品実装は行わない。

理由:
- 要件と設計制約を先に固める必要があるため。

状態:
- 合意済み

### D-004
決定:
- 仕様書、コメント、UI 文言は原則として日本語で記述する。

理由:
- レビューと合意形成を日本語中心で円滑に行うため。

状態:
- 合意済み

### D-005
決定:
- `spec/` 配下のファイル名は、明確な理由がない限り日本語とする。
- `spec/` 配下以外では、日本語ファイル名を禁止する。

理由:
- 設計文書は可読性を優先し、実装領域はツール互換性と運用安定性を優先するため。

状態:
- 合意済み

### D-006
決定:
- `spec/05-VSCode連携.md` は混在名を許可する。

理由:
- VS Code は製品固有名として認知されており、日本語題名の可読性と対象範囲の明確さを両立しやすいため。

状態:
- 合意済み
