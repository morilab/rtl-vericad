# rtl-vericad

## プロジェクト概要
GUI ベースの検証環境をお手軽に構築する CAD アプリ開発を目的としたプロジェクトです。RTL 設計の初期検証から CAD フロー連携までを GUI で直感的に扱えるようにし、スクリプト依存の立ち上げ作業を減らします。

## GUI アプリのセットアップ
GUI ツールはローカル環境での利用を想定しています。以下の手順は Linux デスクトップ (Ubuntu 22.04 以降) を推奨環境として記載しています。

### 依存ライブラリ
- Python 3.11 以降
- pip と venv (Python 標準の仮想環境ツール)
- GTK または Qt のランタイム一式 (デスクトップ環境に合わせてインストールしてください)
- 既存の RTL シミュレーションで利用する外部 EDA ツール一式 (例: Icarus Verilog, Verilator など)

### ビルド/起動方法
1. 仮想環境を作成して依存関係をインストールします。
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. 開発用の GUI アプリを起動します。
   ```bash
   python -m rtl_vericad.gui
   ```
   実行後、ローカルディスプレイにウィンドウが立ち上がり、プロジェクト作成や RTL 追加を GUI で操作できます。

### 推奨 OS と環境
- Ubuntu 22.04 以降の X11 または Wayland 環境
- GUI をリモート表示する場合は X forwarding ではなく VNC/リモートデスクトップ系を推奨
- EDA ツールの PATH が GUI からも参照できるよう、起動前に環境変数を設定してください

## 想定ワークフロー
1. **プロジェクト作成**: GUI から新規プロジェクトを作成し、ワークスペースとターゲットデバイス/ライブラリを設定します。
2. **RTL 追加**: GUI 上で RTL ソースを追加・管理し、階層構造や依存関係を整理します。
3. **シミュレーション/波形閲覧**: シミュレーション条件を GUI で設定して実行し、結果を内蔵の波形ビューアで確認します。
4. **CAD フロー連携**: 合成・配置配線などの CAD フローを GUI から呼び出し、ログや成果物をプロジェクトにひも付けて管理します。

## 既存シミュレーションスクリプトとの関係
CLI ベースのシミュレーションスクリプトは、GUI から呼び出す実行エンジンとして利用します。GUI では以下を前提にしています。
- スクリプトは単体でも動作可能で、GUI はパラメータ生成と実行トリガーのみを行います。
- GUI からの呼び出し時は、ワークスペースに合わせて作業ディレクトリや環境変数を自動設定します。
- スクリプト側が要求する外部ツールやライセンスは GUI では補完できないため、事前に CLI で動作確認済みの環境を用意してください。

これらを踏まえて、GUI を導入しても既存フローの互換性を保ちつつ、操作性と可視性を向上させることを目指します。
